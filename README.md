## Overview

FIR RACK is a remix of [Lab Rax](https://makerworld.com/en/models/1294480-lab-rax-10-server-rack-5u#profileId-1325352) by mklements. It takes after Lab Rax in ease of assembly and overall look, but it was designed from scratch. It is not compatible with Lab Rax.

## Features

FIR RACK keeps what makes Lab Rax great, with these improvements:

* Side panels can be removed without taking the rack apart
* Nuts on the mounting rails are easy to install and remove
* More stable feet
* Deeper frame: 240 mm → 260 mm
* Support rails for heavy shelves (optional)

## Expandability

* **Rack height**<br>
    FIR RACK is 5U. With the extension kit you can add 3U or 5U. For example, adding 3U to a 5U rack gives you an 8U rack.
* **Support rails**<br>
    For heavy shelves, the optional support rails take the load off the mounting rails.

## 4 print profiles

FIR RACK has four profiles. For a minimal rack, the BASIC profile is all you need.

| Profile | What's included | Notes |
|---|---|---|
| BASIC | Core frame parts | Required |
| PANEL | Top, bottom, and side panels | Optional |
| EXTEND | Extension kit parts | Optional |
| RAIL | Support rails | Optional |

## Hardware

Parts you need to assemble FIR RACK:

| Part | Qty | Notes |
|---|---:|---|
| M6 nuts | 24 | Required |
| M6 pan-head screws, 12 mm | 24 | Required |
| M3 nuts | 16 | For side panels (optional) |
| M3 pan-head screws, 12 mm | 16 | For side panels (optional) |
| M6 nuts | 8 | For the extension kit (optional) |
| M6 pan-head screws, 12 mm | 8 | For the extension kit (optional) |
| M3 nuts | 12 | For the extension kit (optional) |
| M3 heat-set inserts (OD 5 mm, length 4 mm) | 32 | For support rails (optional) |
| M3 screws, 5 mm | 12 | For support rails (optional) |

You will also need extra M6 nuts and 12 mm M6 screws for the shelves you install.
